# 🎬 엔터·미디어 회계 인사이트 레이더

엔터테인먼트·미디어 산업에서 감사 실무상 판단이 걸리는 5가지 주제를 매주 자동으로 추적하는 개인용 인사이트 대시보드입니다.

- 콘텐츠 자산화·상각 (제작비 자산화, 손상차손, 판권 무형자산)
- 수익인식 (OTT·콘텐츠 매출 인식 시점, 광고매출)
- 우발부채·소송 (정산 분쟁, 출연료 미지급 소송)
- 지배구조·합병 (엔터사 M&A, 지분인수)
- 정책·지원제도 (콘텐츠산업 지원정책, 저작권법 개정)

## 구조

- `crawler.py` — 네이버 뉴스 검색 API(NAVER API HUB)로 카테고리별 키워드 뉴스를 수집해 `data/news_log.csv`에 누적. 3단계 필터링을 거침:
  1. **가십 제외어**: 열애·결별·재혼 등 인적 스캔들 단어가 있으면 제외
  2. **업계 맥락 화이트리스트**: 특정 엔터·미디어·게임/웹툰 기업명이나 업계 고유용어가 본문에 하나도 없으면 제외 (범용 단어 "영상"·"콘텐츠"만으로 걸리는 오탐 차단). "합병"·"M&A"·"지분인수"처럼 그 자체가 산업 불문 통용어인 키워드는 범용 업계 단어로는 부족하고 **실제 회사명**이 있어야만 통과하도록 더 엄격하게 적용
  3. **회계·법률 앵커 용어**: 키워드별로 지정된 핵심 용어(예: "손상차손", "매출인식")가 실제 본문에 있어야 통과. 일부 키워드(예: "무형자산 손상차손")는 여러 용어가 **모두** 있어야 하는 AND 조건으로 정밀도를 더 높임
  이후 같은 사건을 다룬 기사는 제목 핵심단어 중복비율로 묶어 주요언론사·최신순 상위 3건만 남기고,
  키워드당 최종 8건으로 상한을 둠. 검색량이 적고 정확도가 중요한 키워드는 최신순 대신 관련도순(sim)으로 조회
- `.github/workflows/weekly_crawl.yml` — 매주 일요일 09:00(KST) GitHub Actions가 크롤러를 실행하고 결과를 자동 커밋
  (최초 실행은 2026-07-28 화요일 수동 시드, 이후 매주 일요일 자동 실행)
- `app.py` — 누적 데이터를 기반으로 한 Streamlit 대시보드 (카테고리별 주간 막대 트렌드, 키워드별 접이식 기사 목록)

## 왜 '시점의 대시보드'가 아니라 '누적형'인가

일회성 크롤링은 특정 시점의 스냅샷만 보여줍니다. 이 프로젝트는 GitHub Actions로 매주 자동 수집·커밋되어,
데이터가 쌓일수록 "카테고리별 언급 빈도가 시간에 따라 어떻게 변하는지" 트렌드를 볼 수 있고,
커밋 로그 자체가 꾸준히 관리해온 이력으로 남습니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 크롤러 수동 실행 (환경변수 필요)

```bash
export NAVER_CLIENT_ID=xxx
export NAVER_CLIENT_SECRET=xxx
python crawler.py
```

GitHub Actions에서 실행하려면 리포지토리 Settings → Secrets and variables → Actions에
`NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`을 등록해야 합니다.
